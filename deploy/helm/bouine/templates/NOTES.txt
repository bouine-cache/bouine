== Admin token ==

If you did not set an admin token explicitly, bouine auto-generated one at
startup. Check the pod logs:
    kubectl logs --namespace {{ .Release.Namespace }} {{ include "bouine.fullname" . }}-0 | grep -i "token"

To set a token, inject it via an environment variable:
    extraEnv:
      - name: BOUINE_ADMIN_TOKEN
        valueFrom:
          secretKeyRef:
            name: bouine-admin-token
            key: token

== Next steps ==

1. Configure upstream pools and routes in your values:
    config:
      upstream_pools:
        - name: app
          targets: ["app.default.svc:8080"]
      routes:
        - match: {}
          pool: app
          cache:
            ttl_default: 60s

2. Verify the cache:
    kubectl port-forward --namespace {{ .Release.Namespace }} svc/{{ include "bouine.fullname" . }} 8080:{{ .Values.service.httpPort }}
    curl -sI http://localhost:8080/ | grep x-cache
