# Agent coordination notes

Per `AGENTS.md §15`, cross-package changes require posting a
coordination note here and waiting for acknowledgement (or 24 hours,
whichever comes first).

Format (newest at the top):

```markdown
## YYYY-MM-DD — short title — agent-id

**Scope**: which packages / files are affected.
**Reason**: why this is cross-package (interface change, shared type,
config schema, etc.).
**Acknowledged by**: list of agent-ids that have seen this.
**Resolved**: YYYY-MM-DD (when conflict closed).
```
