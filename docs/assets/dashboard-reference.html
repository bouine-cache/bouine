Invalidation

purge · ban · refresh — broadcast to all cluster peers
Purge — exact URL
Removes the exact cache key. In a cluster, forwarded to the key's owner node. Vary variants are all purged.
Ban — predicate
Lazy predicate — entries are checked on next lookup. Broadcast to all peers.
Refresh — soft-purge
Marks entry stale. Next request revalidates with origin using If-None-Match. If origin returns 304, cached body reused.
